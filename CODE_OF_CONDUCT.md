# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be respectful in issues, pull requests, and reviews.

Report unacceptable behavior to the maintainer through the contact on [github.com/dovys](https://github.com/dovys). Reports are kept confidential. The maintainer may edit or remove comments, close threads, or block contributors who break the code.
